GAYATHRI K R PORTFOLIO
======================

Files
-----
- index.html : portfolio content
- style.css  : responsive dark neon styling
- script.js  : mobile navigation, current year, email form
- assets/    : place your resume PDF here

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Install the "Live Server" extension if you do not have it.
4. Right-click index.html and choose "Open with Live Server".

BEFORE PUBLISHING — IMPORTANT
-----------------------------
1. In index.html, replace every "your.email@example.com" with your real email.
2. Replace "+91 XXXXX XXXXX" with your phone number.
3. Update LinkedIn and GitHub links with your profile URLs.
4. Add your resume PDF to assets/ and name it exactly:
   Gayathri_KR_Resume.pdf
5. The portrait is currently a stylized GK placeholder. To use your photo:
   - Add your photo to assets as portrait.jpg.
   - Replace the <div class="portrait-placeholder">...</div> in index.html
     with: <div class="portrait-placeholder"><img src="assets/portrait.jpg" alt="Gayathri K R"></div>
   - Add this CSS rule to style.css:
     .portrait-placeholder img { width:100%; height:100%; object-fit:cover; border-radius:inherit; }
6. Confirm project details, dates, scores, and links are correct before sharing.

CONTACT FORM
------------
The form opens the visitor's default email app. It does not send messages directly
from the website; direct submission needs a backend or a form service.

TECH
----
HTML, CSS, JavaScript. No build tools or installation required.
